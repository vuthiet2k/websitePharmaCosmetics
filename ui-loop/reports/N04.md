Đề xuất thay đổi thư viện: không (đợt 0 — sửa trực tiếp, ghi changelog v1.1)

### Nguyên nhân (đo trước sửa, `ui-loop/checks/N04.mjs --before`)
- `assets/vendor_bootstrap.css`: `button, input { outline: none !important }` ⇒ mọi `<button>` / `<input>` thư viện mất viền
  (đo: `button.pc-btn` none, `.pc-input` none, `.pc-modal__close` none).
- `assets/storefront-v3.css`: `.pc-site-v3 :is(a,button,input):focus-visible { outline: 3px solid #3CB371; outline-offset: 4px }`
  (độ ưu tiên 0,2,1) thắng `:focus-visible` của tokens.css (0,1,0) ⇒ `a.pc-btn` có viền 3px rgb(60,179,113) thay vì 2px brand.
- `assets/global_core.scss.bwt`: `a, button…:focus { outline: none }` (0,1,1) cũng thắng tokens.css.

### Cách sửa
1. `vendor_bootstrap.css`: tách `outline: none !important` ra quy tắc
   `:where(button, input):where(:not(.pc-btn, .pc-swiper-btn, .pc-modal__close, .pc-input, .pc-header__icon, .pc-bottomnav__item))`
   — độ ưu tiên 0, phần tử cũ vẫn bị tắt viền như trước (không đổi giao diện trang cũ); số `!important` không tăng.
2. `components.css` v1.1: nhóm "0. Viền focus" `:root :is(.pc-btn, .pc-swiper-btn, .pc-modal__close, .pc-input, .pc-fab,
   .pc-header__icon, .pc-bottomnav__item):focus-visible { outline 2px solid brand; offset 2px }` — `:root` cho độ ưu tiên
   (0,3,0) thắng quy tắc cũ, không cần `!important`; bỏ `:root` ở D09. `.pc-input` bỏ `focus:outline-none focus:ring-2
   focus:ring-brand` (ring bị đè thành 2 lớp viền), giữ `focus:border-brand` + viền chung.
