  frown, circle-dot, sun, hourglass, droplet, wand-sparkles).
- 11 snippet/template khung chung: 57 lượt FA → `ui_icon` (ui-guard `faIcon` 11 file về 0).
- `snippets/mobile_bottom_nav.bwt`: icon tab đọc settings qua `ui_icon` (hiểu giá trị FA cũ), không vẽ được ⇒ icon mặc định của tab.
- CSS cũ tô đặc icon nét (đo được ở vòng này): `snippets/pharma_ui_kit.bwt` 7 quy tắc `… svg path { fill }` và
  `assets/global_core.scss.bwt` `.main-widget .item svg` / `.def-content .item svg` ⇒ giới hạn `svg:not([fill="none"])`;
  xoá quy tắc `svg 32px + path fill` của SVG hamburger cũ (global_core).
