Việc / mã lỗi: N09 (đợt 0) — CSS cũ `global_core.scss.bwt` `label { display: inline-block !important }` đè `inline-flex` của `.pc-check`
Luồng bị ảnh hưởng: Form (checkbox `ui_field` — đồng ý / nhận tin); chưa template nào dùng ngoài trang kit
File đã sửa: assets/global_core.scss.bwt (CSS cũ đóng băng — chỉ thu hẹp phạm vi quy tắc, không thêm khai báo)
Cách sửa: `label` → `label:where(:not(.pc-check))` (cùng cách N04 ở vendor_bootstrap.css): độ ưu tiên vẫn 0,0,1, mọi label cũ
  giữ `inline-block !important`; riêng `label.pc-check` nhận `inline-flex` (gap-3, items-center) từ components.css. Xoá cả quy tắc ở D09.
Component đã dùng: ui_field (type checkbox) — không sửa thư viện
Đề xuất thay đổi thư viện: không
