# Đề xuất L03a — JS jQuery / Swiper / LazyLoad nạp `defer` (vòng 40, 30/10/2026)

**Trạng thái:** chờ chủ dự án quyết (BLOCKED_OWNER). Chưa sửa mã theme.

## Phần đã xong của L03a

- Font: N19 (commit b2f411a) đã tự host Montserrat tĩnh 400/500/600/700, gỡ Google Fonts; N21 (02ea258) bỏ độ đậm 300/800.
  Còn lại của L03a chỉ là "JS jquery/swiper/lazy không chặn hiển thị".

## Vấn đề (đo bằng trình duyệt, vòng 40)

`layouts/theme.bwt:67-72` nạp `jquery.js`, `swiper.js`, `lazy.js` **đồng bộ trong `<head>`**. Thêm `defer` thẳng vào 3 thẻ
(thử bằng `page.route`, không sửa file — `ui-loop/evidence/L03a/probe-defer-gain.mjs`, cùng điều kiện ui-verify --perf: 390
Chromium, 1,6 Mbps, RTT 150ms, CPU 4×, trung vị 3 lần):

| Trang | FCP hiện tại → defer | LCP hiện tại → defer | Lỗi JS phát sinh khi defer |
| :-- | :-- | :-- | :-- |
| / | 8 396 → 6 920 ms | 9 128 → 8 576 ms | 3 (`$ is not defined`, `jQuery is not defined`, `theme is not defined`) |
| /collections/all | 6 032 → 5 580 ms | 12 172 → 9 396 ms | 3 |
| /products/serum-vitamin-c-15 | 6 176 → 5 780 ms | 7 344 → 6 612 ms | 5 (thêm `Swiper is not defined`, `reading 'fn'`) |
| /tin-tuc | 6 780 → 5 596 ms | 7 972 → 6 636 ms | 3 |

⇒ lợi FCP 0,4–1,5 s, nhưng **defer trần làm hỏng chức năng** vì script nội tuyến chạy lúc parse, trước khi file defer chạy:

- `ui-loop/evidence/L03a/scan-inline.mjs jq`: **45 khối `<script>` nội tuyến** gọi `$`/`jQuery` (≈ 40 file: `quickview-buy`,
  `ajaxcartfunction`, `product.bwt`, `cart.bwt`, `addresses.bwt`, `vat-cart`, `favorite_js`, `section_flash_sale` — file chủ dự
  án đang sửa dở —, …); 8 khối gọi `new Swiper` ngay lúc parse (`article.bwt`, `product.bwt`, `pc_brands_carousel_script`,
  `section_spa`, `page_tin_tuc_hub`, `page.indexskinhealthy`…).
- Script ngoài đồng bộ trong `<body>` phụ thuộc jQuery: `jquery-ui-min.js`, `jquery.ui.touch-punch` (CDN), `search_filter.js`,
  `col.js`, `picbox.js` (footer_script), `appbulk-product-statistics.js`, `jquery.validate` (addresses), `bootstrap-datepicker`,
  `sweetalert` (cart), `tabletop.js`, `cookie.js`; ở trang customer `bizweb-api.js` / `common.js` / `customer.js` của Sapo.
- **B.5** ghi "jQuery chỉ giữ cho plugin Sapo còn phụ thuộc" — script app Sapo chèn qua `content_for_header` trên Sapo thật
  (app đánh giá, appbulk…) có thể cần jQuery đồng bộ; local không có các script này ⇒ không kiểm được (đã quyết: không kiểm
  Sapo thật).

## Phương án

1. **(Khuyến nghị) Defer cả 3 + bọc script nội tuyến.** Thêm `defer` cho jquery/swiper/lazy; mọi script ngoài phụ thuộc
   trong body cũng `defer` (giữ thứ tự); bọc 45 + 8 khối nội tuyến trong `document.addEventListener('DOMContentLoaded', …)`,
   hàm dùng ở `onclick="…"` gán lại `window.x = x`. Chạm ≈ 40 file (gồm `section_flash_sale.bwt` đang sửa dở) — làm theo
   nhóm (trang chủ / danh mục / sản phẩm / giỏ / tài khoản / blog), mỗi nhóm 1 việc con, kiểm chức năng từng trang.
   Rủi ro: app Sapo thật cần jQuery đồng bộ (không kiểm được ở local).
2. **Defer Swiper + LazyLoad, giữ jQuery đồng bộ** (đúng B.5). Bọc 8 khối Swiper nội tuyến; ít rủi ro; lợi ích nhỏ hơn
   (swiper.js 96KB + lazy 5,5KB; jQuery 89KB vẫn chặn).
3. Giữ nguyên, bỏ phần JS khỏi L03a (L03a = DONE theo phần font); xử lý tốc độ ở L03b (Font Awesome CSS chặn hiển thị) / L03c.

Lưu ý: kể cả khi defer, FCP vẫn 5,6–6,9 s (ngưỡng 1,8 s) — phần lớn do ~12 file CSS chặn hiển thị + Font Awesome CSS CDN
(L03b) + ảnh (L03c). Defer JS một mình không đưa trang về ngưỡng G.7.
